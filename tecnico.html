HTML5 y CSS en esta evidencia

</>

HTML5

Define la estructura y el significado del contenido con etiquetas semánticas como header, nav, main, section y footer. Es el esqueleto sobre el que se apoya todo lo demás.

🎨

CSS

Le da identidad visual a esa estructura: colores, espaciados, tipografía y una cuadrícula que se adapta a distintas pantallas mediante una media query.

⚙

Navegación entre páginas

Cada opción del menú es un enlace <a href="..."> a un archivo HTML distinto, no un ancla dentro de la misma página. Así se navega entre páginas reales.

Etiquetas explicadas

Lo esencial de cada archivo

DOCTYPE html indica que el documento usa HTML5. html envuelve toda la página y declara el idioma. head contiene metadatos y el enlace al CSS. body contiene todo lo visible: header, nav, main y footer. Cada página de este sitio repite esta misma estructura, cambiando solo el contenido dentro de main.
